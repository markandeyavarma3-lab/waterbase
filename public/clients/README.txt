CLIENT / COMPANY LOGOS — "Companies we've delivered for" carousel
=================================================================

Drop logos of the companies you've done work for into THIS folder
(public/clients/). They appear in the 3-card carousel on the
homepage, where the middle card enlarges and auto-advances every
few seconds.

HOW TO USE
----------
1. Save each logo as a PNG (transparent background looks best),
   or SVG / JPG / WEBP also work.
2. Recommended size: about 400 x 160 px, logo centered.
3. Name the file after the company, e.g.:
      nuziveedu-seeds.png
      patanjali.png
   The filename is turned into the label shown under the logo:
      "nuziveedu-seeds.png"  ->  "Nuziveedu Seeds"
4. Add as many as you like.
5. Commit + push (or tell Claude to push) -> Vercel rebuilds and
   the logos go live.

NOTE
----
Unlike the brand strip, here the company NAME (from the filename)
IS shown under each logo — so name the files carefully.
